# Pong (Godot)

A two-player Pong clone built with [Godot Engine](https://godotengine.org/) 4.7.

> **⚠️ Work in Progress**
> This project is in a very early stage of development. The core gameplay loop is not
> implemented yet — see [Current Status](#current-status) for details.

## Current Status

The project currently contains the project skeleton and a handful of placeholder
scenes. What exists today:

| Piece | Status |
| --- | --- |
| Project configuration | ✅ Done |
| `player.tscn` (paddle) | 🚧 Scene only — no script, cannot move yet |
| `wall.tscn` | 🚧 Scene only — stub script, not instanced in the main scene |
| Ball | ❌ Not started |
| Input Map | ❌ Not started |
| Score / UI | ❌ Not started |

All visuals are currently the **default Godot icon** used as placeholder art.

### Known Issues

- The ball — the central object of the game — does not exist yet.
- `wall.tscn` is not instanced in `main.tscn`, so it does not appear when running.
- `wall.tscn` uses `CharacterBody2D`; a static wall should use `StaticBody2D`.
- `script/wall.gd` is an empty stub with an unused variable and unused parameter.
- `player.tscn` has no script attached, so the paddle cannot be controlled.
- No `[input]` section exists in `project.godot`, so no Input Map actions are defined.
- The `Camera2D` is nested inside `player.tscn` with effectively unlimited bounds,
  which lets the camera drift off into empty space.

## Requirements

- **Godot 4.7** or newer ([download](https://godotengine.org/download))

No additional dependencies. Rendering uses the `gl_compatibility` backend, so the
project runs on low-end hardware and most older integrated GPUs.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/OakJustify/Pong-Godot.git
   cd Pong-Godot
   ```

2. Open the project in the Godot editor:

   ```bash
   godot --editor .
   ```

   Or open the Godot Project Manager, click **Import**, and select `project.godot`.

3. Press **F5** (or click the ▶ button) to run the project.

The main scene is `scene/main.tscn`.
